#  CookLab 🍽️📚

> Um projeto acadêmico que une elegância e culinária.

## 📖 Sobre o projeto

CookLab é um livro de receitas digital elegante, criado para transmitir qualidade e finesse. O projeto nasceu como uma iniciativa acadêmica para explorar a interseção entre design, tecnologia e gastronomia, proporcionando uma experiência sofisticada e intuitiva.

## ✨ Características

- 📚 **Criação e Salvamento de Receitas**: Os usuários podem criar, personalizar e salvar suas próprias receitas de forma organizada.
- 📜 **Estilo Clássico**: Interface inspirada em livros de receitas tradicionais, com tons suaves e aparência refinada.
- 📖 **Navegação Intuitiva**: Estruturado para que qualquer usuário tenha uma experiência fluida e agradável.

## 🚀 Objetivo do Projeto

O principal objetivo do CookLab é ser um livro de receitas digital que não seja apenas funcional, mas que transmita qualidade, elegância e finesse, proporcionando aos usuários uma experiência culinária completa.

## 🛠️ Tecnologias Utilizadas

- HTML e CSS para estruturação e animações
- Markdown para documentação
