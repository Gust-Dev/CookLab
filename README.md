#  CookLab 🍽️🎨

> Um projeto acadêmico que une arte e culinária de um jeito único!

## 📖 Sobre o projeto

CookLab é um livro de receitas interativo que combina o charme dos livros de receitas antigos com um toque moderno de pixel art. O projeto nasceu como uma iniciativa acadêmica para explorar a interseção entre design, tecnologia e gastronomia, trazendo uma experiência visualmente envolvente e nostálgica.

## ✨ Características

- 📚 **Criação e Salvamento de Receitas**: Os usuários podem criar, personalizar e salvar suas próprias receitas dentro do sistema.
- 📜 **Estilo Retro**: Interface inspirada em livros antigos, mas com uma estética em pixel art.
- 🎮 **Pixel Art Design**: Ilustrações e elementos gráficos no estilo pixelado para dar um charme único.
- 🏆 **Sistema de Conquistas**: Desbloqueie conquistas ao explorar e criar receitas, incentivando a experimentação culinária.
- 📚 **Fácil Acesso**: Estruturado para ser intuitivo e acessível para qualquer usuário.

## 🚀 Objetivo do Projeto

Nosso principal objetivo é criar um livro de receitas digital que não seja apenas funcional, mas que explora a ideia da nostalgia dos jogos antigos, foi pensado para transmitir uma sensação de nostalgia, misturando tradição e inovação.

## 🛠️ Tecnologias Utilizadas

- HTML e CSS para estruturação e animações
- Aseprite para criação de pixel art
- Markdown para documentação

Desenvolvido com ❤️ para tornar a culinária mais divertida e visualmente envolvente!
